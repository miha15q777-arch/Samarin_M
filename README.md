## Описание проекта
Графическое приложение для управления личной коллекцией фильмов. Программа позволяет добавлять новые фильмы в базу данных, просматривать их в виде таблицы и фильтровать по жанру и году выпуска. Все данные надежно сохраняются в формате JSON.

## Требования

*   **Язык программирования:** Python версии 3.8 или выше.
*   **Используемые библиотеки:**
    *   `tkinter`: Входит в стандартную библиотеку Python (не требует установки через pip).
*   **Операционная система:** Windows, macOS или Linux.

## Инструкция по запуску

1.  Убедитесь, что у вас установлен Python 3.8+.
2.  Скачайте или склонируйте этот репозиторий.
3.  Перейдите в папку проекта в терминале.
4.  Запустите приложение командой:
    ```bash
    python main.py
    ```

## Функциональность приложения

1.  **Добавление фильма:** Заполните поля `Название`, `Жанр`, `Год` и `Рейтинг`, затем нажмите кнопку `Добавить фильм`.
2.  **Валидация ввода:** Программа проверяет корректность данных перед добавлением.
3.  **Фильтрация:** Используйте выпадающий список и поле для ввода года над таблицей. Нажмите `Применить фильтр`.
4.  **Сохранение данных:** Все изменения автоматически сохраняются в файл `movies.json`.

## Примеры использования и тестирование

### Позитивные тесты (должны работать):
*   **Добавление фильма:** Вводим *"Начало"*, *"Фантастика"*, *"2010"*, *"8.8"*. Фильм появляется в таблице.
*   **Граничные значения рейтинга:** Успешно добавляются фильмы с рейтингом *"0.0"* и *"10.0"*.
*   **Фильтрация:** Выбор жанра *"Комедия"* скрывает все фильмы других жанров.
*   **Сброс фильтра:** Вводим данные для фильтра, применяем, затем меняем поля фильтра на пустые/стандартные и применяем снова — видим полный список.

### Негативные тесты (должны выдавать понятное сообщение об ошибке):
*   **Пустое название:** Нажатие `Добавить фильм` вызывает окно с текстом: "Поле 'Название' не может быть пустым".
*   **Некорректный год (текст):** Вводим *"две тысячи"*. Вызывает ошибку: "Поле 'Год' должно содержать целое число".
*   **Некорректный год (вне диапазона):** Вводим *"1850"*. Вызывает ошибку: "Год должен быть в диапазоне от 1888 до 2026".
*   **Некорректный рейтинг (текст):** Вводим *"десять"*. Вызывает ошибку: "Поле 'Рейтинг' должно быть числом (например, 8.5)".
*   **Некорректный рейтинг (вне диапазона):** Вводим *"15"*. Вызывает ошибку: "Рейтинг должен быть в диапазоне от 0.0 до 10.0".
