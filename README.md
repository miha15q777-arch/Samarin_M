# Movie Library (Личная кинотека)

**Автор:**  Samarin_M

**Описание:**
Приложение для хранения и фильтрации личной коллекции фильмов. Позволяет добавлять, удалять, фильтровать по жанру и году, сохранять данные в JSON.

**Технологии:**
- Python 3.6+
- tkinter

**Примеры использования:**
1. Запустите `main.py`.
2. Введите данные о фильме и нажмите «Добавить фильм».
3. Используйте фильтры для поиска.
4. Данные сохраняются в `movies.json`.
