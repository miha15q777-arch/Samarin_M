## Описание проекта

Графическое приложение для генерации надежных паролей. Программа позволяет настраивать сложность пароля (длину и используемые символы), генерировать его одним кликом и сохранять историю последних 20 сгенерированных вариантов. Все данные истории хранятся локально в формате JSON.

## Требования

*   **Язык программирования:** Python версии 3.8 или выше.
*   **Используемые библиотеки:**
    *   `tkinter`: Входит в стандартную библиотеку Python.
*   **Операционная система:** Windows, macOS или Linux.
*   **Модули Python:** Используются стандартные модули `random`, `string`, `json`, `datetime`.

## Инструкция по запуску

1.  Убедитесь, что у вас установлен Python 3.8+.
2.  Скачайте или склонируйте этот репозиторий.
3.  Перейдите в папку проекта в терминале.
4.  Запустите приложение командой:
    ```bash
    python main.py
    ```

## Функциональность приложения

1.  **Настройка длины:** Используйте ползунок для выбора длины пароля от 4 до 128 символов.
2.  **Выбор символов:** Отметьте галочками типы символов, которые должны быть в пароле (прописные/строчные буквы, цифры, знаки пунктуации).
3.  **Генерация:** Нажмите кнопку **«Сгенерировать пароль»**.
4.  **Результат:** Сгенерированный пароль появится в поле сверху.
5.  **Копирование:** Нажмите кнопку **«Копировать»**, чтобы поместить пароль в буфер обмена.
6.  **История:** Все сгенерированные пароли сохраняются в список внизу окна.
7.  **Безопасность:** Приложение гарантирует наличие хотя бы одного символа из каждого выбранного вами типа.

## Примеры использования и тестирование

### Позитивные сценарии:
*   **Базовая генерация:** Оставьте все галочки включенными и нажмите «Сгенерировать». Вы получите сложный пароль.
*   **Копирование:** Сгенерируйте пароль и нажмите «Копировать». Вставьте его в текстовый редактор — он должен совпасть.
*   **История:** Сгенерируйте несколько разных паролей. Все они должны появиться в списке «История».
*   **Граничные значения:** Установите ползунок на минимальное значение (4) и максимальное (128) — генерация должна пройти успешно.
*   **Специфические настройки:** Отключите все чекбоксы кроме «Цифры» и сгенерируйте пароль — он должен состоять только из цифр.
