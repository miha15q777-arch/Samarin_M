## Описание проекта

Графическое приложение для поиска пользователей на платформе GitHub с помощью официального **GitHub API**. Программа позволяет находить пользователей по логину или имени, просматривать результаты в виде таблицы и управлять списком избранных пользователей. Данные об избранном сохраняются локально в формате JSON.

## Требования

*   **Язык программирования:** Python версии 3.8 или выше.
*   **Используемые библиотеки:**
    *   `tkinter`: Входит в стандартную библиотеку Python.
    *   `requests`: Для выполнения HTTP-запросов к GitHub API. Устанавливается через `pip install requests`.
*   **Операционная система:** Windows, macOS или Linux.

## Инструкция по запуску

1.  Установите Python 3.8+ и библиотеку `requests`:
    ```bash
    pip install requests
    ```
2.  Скачайте или склонируйте этот репозиторий.
3.  Перейдите в папку проекта в терминале.
4.  Запустите приложение командой:
    ```bash
    python main.py
    ```

## Функциональность приложения

1.  **Поиск:** Введите логин или имя пользователя (например, `torvalds` или `mojombo`) в поле поиска и нажмите кнопку **«Найти»**.
2.  **Просмотр результатов:** Найденные пользователи отображаются в таблице с колонками: Логин, ID и Тип.
3.  **Избранное:**
    *   Кликните правой кнопкой мыши (ПКМ) на пользователя в таблице.
    *   Выберите **«Добавить в избранное»** или **«Удалить из избранного»**.
    *   Избранные пользователи подсвечиваются светло-зеленым цветом.
4.  **Сохранение:** Список избранных сохраняется в файл `users.json` и загружается при запуске программы.

## Примеры запросов к API и обработка ошибок

Приложение корректно обрабатывает различные сценарии работы с сетью и API.

### Позитивный сценарий (Успех):
*   **Запрос:** Вводим `torvalds` и нажимаем «Найти».
*   **Результат:** В таблице появляется пользователь `torvalds` (Линус Торвальдс).
*   **API Статус:** `200 OK`.

### Сценарии ошибок (Обработка исключений):
*   **Сетевая ошибка (Нет интернета):**
    *   **Действие:** Нажимаем «Найти» без подключения к сети.
    *   **Результат:** Появляется окно с ошибкой: "Сетевая ошибка. Не удалось подключиться к серверу".
*   **Ошибка валидации ввода:**
    *   **Действие:** Оставляем поле поиска пустым и нажимаем «Найти».
    *   **Результат:** Появляется предупреждение: "Поле поиска не может быть пустым".
*   **Ошибка API (Лимит запросов):**
    *   **Действие:** Выполняем очень много запросов за короткое время без авторизации на GitHub.
    *   **Результат:** Появляется окно с ошибкой: "Превышен лимит запросов к GitHub API. Попробуйте позже".
