## Описание проекта

Графическое приложение для управления личной коллекцией фильмов. Программа позволяет добавлять новые фильмы в базу данных, просматривать их в виде таблицы и фильтровать по жанру и году выпуска. Все данные надежно сохраняются в формате JSON.

## Технологии

*   **Язык программирования:** Python 3.x
*   **Библиотеки:** `tkinter` (стандартная библиотека для GUI), `json`.
*   **Система контроля версий:** Git.
*   **Хостинг репозитория:** GitHub.

## Инструкция по запуску

1.  **Установите Python** версии 3.6 или выше с официального сайта `python.org`.
2.  **Скачайте или склонируйте** этот репозиторий на свой компьютер.
    ```bash
    git clone https://github.com/ВашЛогин/Movie_Library.git
    ```
3.  Перейдите в папку проекта:
    ```bash
    cd Movie_Library
    ```
4.  Запустите приложение:
    ```bash
    python main.py
    ```

## Функциональность приложения

1.  **Добавление фильма:** Заполните поля `Название`, `Жанр`, `Год` и `Рейтинг`, затем нажмите кнопку `Добавить фильм`.
2.  **Валидация ввода:** Программа проверяет корректность данных:
    *   Поле `Название` не может быть пустым.
    *   Поле `Год` должно содержать целое число в диапазоне от 1888 до 2026 года.
    *   Поле `Рейтинг` должно быть числом от 0 до 10.
3.  **Фильтрация:** Используйте выпадающий список и поле для ввода года над таблицей. Нажмите `Применить фильтр`, чтобы отобразить только подходящие фильмы.
4.  **Сохранение данных:** Все изменения (добавление фильмов) автоматически сохраняются в файл `movies.json`. При следующем запуске программа загрузит данные из этого файла.

## Примеры использования и тестирование

### Позитивные тесты (должны работать):
*   **Добавление фильма:** Вводим *"Начало"*, *"Фантастика"*, *"2010"*, *"8.8"*. Фильм появляется в таблице.
*   **Граничные значения рейтинга:** Успешно добавляются фильмы с рейтингом *"0.0"* и *"10.0"*.
*   **Фильтрация:** Выбор жанра *"Комедия"* скрывает все фильмы других жанров.

### Негативные тесты (должны выдавать ошибку):
*   **Пустое название:** Нажатие `Добавить фильм` с пустым полем названия вызывает окно с ошибкой.
*   **Некорректный год:** Ввод текста *"две тысячи двадцать"* или числа *"3000"* вызывает ошибку.
  **Некорректный рейтинг:** Ввод текста *"отлично"* или числа *"-5"* вызывает ошибку.
